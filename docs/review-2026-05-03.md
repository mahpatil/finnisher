## Non-Blocking Notes

- [ ] `src/cli/commands/web.ts:13` — **`finn web` breaks after global install** — `../../src/web` from `dist/cli/commands/` resolves correctly in a dev checkout but fails after `npm install -g`. → Add `src/web` to `package.json#files` and fix the relative path. Tracked: `openspec/changes/finn-web-global-path-fix`.

- [ ] `src/web/components/Dashboard.tsx:71` — **`patchThread` errors silently dropped** — PATCH failures leave UI stale until next poll with no user feedback. → Wrap in try/catch, show MUI `Snackbar` on error. Tracked: `openspec/changes/dashboard-patch-error-handling`.

- [ ] `e2e/dashboard.spec.ts:170` — **Done tab max-30 cap untested** — Only a single-thread happy-path test. → Seed 35 done threads, assert count ≤ 30. Tracked: `openspec/changes/dashboard-done-tab-max30-test`.

## Summary

All 5 spec phases are fully implemented: 145 unit tests + 18 Playwright e2e tests, green build. The one item to address before a public release is the `finn web` global path resolution — it will silently fail for anyone who installs via `npm install -g` rather than running from the dev checkout. The two test-coverage gaps (SWR poll e2e, Done tab max-30) and the error-handling gap in `patchThread` are low-urgency but tracked as openspec changes.
